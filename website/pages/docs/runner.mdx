The Runner is the component that takes an ABS document and executes it against a real agent, capturing the trace and evaluating it against the spec.

## Architecture

<Mermaid chart={`
flowchart LR
    A[ABS Document] --> B[Runner]
    B --> C[Agent under test]
    C --> D[Trace]
    D --> E[Evaluations]
    E --> F[Report]
    
    style A fill:#e0e7ff,stroke:#6366f1
    style F fill:#d1fae5,stroke:#10b981
`} />

1. **Parse** the ABS document into a sequence of expected Behaviors.
2. **Execute** by driving the agent — sending user messages, observing responses, detecting tool calls.
3. **Capture** the actual trace (what really happened).
4. **Evaluate** by comparing expected vs. actual, running all evaluations.
5. **Report** the results.

## Adapters

The Runner uses adapters to talk to different agent frameworks:

| Adapter | Status |
|---|---|
| CLI / stdin-stdout | v0.1 — stable |
| HTTP / WebSocket | Planned for v0.2 |
| LangChain callback | Community interest |
| MCP-native | Planned |

## Running a session

```bash
# Against a local CLI agent
abs run session.abs.yaml --adapter cli --command "./my-agent"

# Against an HTTP endpoint
abs run session.abs.yaml --adapter http --endpoint "http://localhost:8080/agent"
```

## The trace

After execution, the Runner produces a **trace** — the actual sequence of observed Behaviors:

```yaml
# trace.abs.yaml (generated)
session: Refund request — approved [TRACE]
behaviors:
  - actor: user
    action: says
    content: "I want to return order #8291, it arrived damaged"
  - actor: assistant
    action: asks
    content: "I'm sorry about that. Can you confirm your name and order date?"
  - actor: user
    action: says
    content: "Franco Vinciarelli, ordered last Tuesday"
  - actor: assistant
    action: calls
    target: Orders API
    with:
      orderId: "8291"
  - actor: Orders API
    action: responds
    content:
      orderId: "8291"
      status: "delivered"
      eligibleForRefund: true
  - actor: assistant
    action: calls
    target: Refunds API
    with:
      orderId: "8291"
      reason: "damaged"
  - actor: Refunds API
    action: responds
    content:
      refundId: "R-5512"
      amount: 47.50
      status: "processed"
  - actor: assistant
    action: informs
    content: "Refund of €47.50 processed, Franco. You'll receive it in 3-5 days. Your refund ID is R-5512."
```

The trace is then compared against the original spec's evaluations.
