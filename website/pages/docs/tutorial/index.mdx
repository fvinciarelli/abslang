## The 20-minute path

1. **[What ABS is and its structure](/docs/tutorial/what-is-abs)** — the acronym, the YAML format, the three fields, the four actors
2. **[Write a real conversation](/docs/tutorial/write-a-conversation)** — model a refund bot step by step: user says, bot asks, APIs are called, bot confirms
3. **[Step-level evaluations](/docs/tutorial/step-evaluations)** — add `llm_judge` for quality checks and `contains` for hard facts
4. **[Chain evaluations](/docs/tutorial/chain-evaluations)** — `sequence`, `never`, `variable_consistency`: properties of the whole trace
5. **[Run it](/docs/tutorial/run-it)** — browser, terminal, or VSCode: three ways to execute against your agent
6. **[Datasets and golden data](/docs/tutorial/datasets)** — from one happy-path test to 100 parameterized runs with `.jsonl`
7. **[Common mistakes](/docs/tutorial/common-mistakes)** — pitfalls every QA hits the first time, and how to avoid them
8. **[Available tools](/docs/tutorial/tools)** — CLI, Designer, VSCode extension, mock agent, chatbot
9. **[Cheat sheet](/docs/tutorial/cheat-sheet)** — all actions and evaluators on one page

Each page takes ~5 minutes. Start at the top and work through — by the end you'll have a complete automated test suite for your agent.
