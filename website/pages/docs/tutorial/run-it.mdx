You've written your spec. Now let's run it.

Three options, from simplest to most integrated:

### 1. Browser — zero install

Open the **[ABS Designer](/abs-designer/)**, paste your YAML, enter your agent URL, ▶ Run. No installation needed.

### 2. Terminal

```bash
abslang run session.abs.yaml --agent http://localhost:8080/chat
```

Prints step-by-step: what matched, what failed, and why.

### 3. VSCode

Open any `.abs.yaml` → the visual editor opens automatically → ▶ Run. Edit visually, save, and run against your agent — all in one place.
